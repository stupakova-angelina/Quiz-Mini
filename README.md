# Quiz Mini — ЕГЭ‑тренажёр в консоли

Консольная обучающая викторина на Python для тренировки перед ЕГЭ. Проект сделан как чистый, понятный учебный код: без лишних зависимостей, с понятными переменными и простой логикой. Отлично подходит для GitHub‑портфолио, заявок на олимпиады (НТО) и целевое обучение.

## Зачем это нужно

- **Подготовка к ЕГЭ.** Вопросы по информатике, математике и русскому языку — можно прогонять перед пробниками и повторять сложные темы.
- **Портфолио для поступления.** Код написан в хорошем стиле: понятные имена переменных, разделение данных и логики, стандартная точка входа `if __name__ == "__main__"`.
- **База для развития.** Легко добавлять новые темы, сохранять результаты, подключать тесты или делать JSON‑вывод — структура уже готова.

## Что умеет

- Показывает вопросы с вариантами ответов.
- Принимает ввод пользователя и проверяет, что это число.
- Перемешивает вопросы при каждом запуске.
- Считает баллы и даёт обратную связь.
- При ошибке показывает правильный ответ и короткое пояснение — чтобы сразу повторить тему.
