# Возможные улучшения проекта 

Пункт 1. Добавить выбор количества вопросов перед стартом
Реализовать ввод числа — сколько вопросов хочет пройти пользователь (максимум столько, сколько есть в базе, либо 0 — чтобы взять все). Добавить проверку: если ввели не число, отрицательное значение или число больше доступного количества — выводить понятное сообщение и запрашивать снова. В конце сессии использовать именно это количество вопросов.

Пункт 2. Добавить расчёт процента правильных ответов и вердикт
После подсчёта баллов вычислить процент: (score / total) * 100, округлить до одного знака после запятой. Вывести строку «Процент правильных: X%». Добавить логику вердикта: при 100 % — «🎉 Идеально!», при более 50 % — «👍 Хорошо, продолжай», иначе — «📚 Есть над чем поработать». Выводить вердикт отдельной строкой.

Пункт 3. Добавить вывод результата в формате JSON
Сформировать словарь с полями score, total, percentage, verdict. Вывести его в консоль как JSON‑строку в отдельной секции «Результат (JSON): ...», используя форматирование с отступами, чтобы JSON был читаемым, и корректную обработку русского текста.
